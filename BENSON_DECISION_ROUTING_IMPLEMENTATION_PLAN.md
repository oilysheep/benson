## 1. Objective, scope and approval boundary

Replace the General Workflow design with authenticated input admission, independent Agent Run settlement, durable domain operation ownership and native event/schedule/delivery mechanisms. Remove prospective JOIN/CLOSE, membership revisions, shared finals, retained orphaned lifecycle state and a global dependency/capacity engine. Preserve Main's bounded semantic coordination, strict completion validation, evidence-based recovery and proven domain safety.

The target is a Deterministic-First, Domain-Owned, Event-Driven Agentic System under Architecture §§1/4/8.1/9. Generic admission routes direct, Main-delegated, event and Automation tasks to one logical owning-domain entry; adequate structured intent requires deterministic handling, and only necessary reasoning requests a fresh authorized domain Run. Main remains the central cognitive orchestrator and sole user-facing agent without a mandatory model hop. Request disposition, Run outcome, physical outcome and delivery outcome remain distinct. A finished Run is never resumed to await a device. Durable Event-Triggered Conditional Actions remain explicitly deferred and visible as a release limitation.
