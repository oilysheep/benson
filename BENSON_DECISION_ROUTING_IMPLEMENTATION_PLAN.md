## 1. Objective, scope and approval boundary

Replace the General Workflow design with authenticated input admission, independent Agent Run settlement, durable domain operation ownership and native event/schedule/delivery mechanisms. Remove prospective JOIN/CLOSE, membership revisions, shared finals, retained orphaned lifecycle state and a global dependency/capacity engine. Preserve Main's bounded semantic coordination, strict completion validation, evidence-based recovery and proven domain safety.

The target must distinguish request disposition, Run outcome, physical outcome and delivery outcome. Domain events may reconcile state deterministically or request a fresh authorized Run. A finished Run is never resumed to await a device. Durable Event-Triggered Conditional Actions remain an explicit deferred capability; their absence from an initial release must be visible.
